# 📚 Portal de Documentación — LNC Producciones

Bienvenido al repositorio central de la documentación técnica y funcional de las aplicaciones y soluciones de TI de **LNC Producciones**.

Este proyecto está construido con **[MkDocs](https://www.mkdocs.org/)** y el tema **[Material for MkDocs](https://squidfunk.github.io/mkdocs-material/)**, y se despliega de forma automática en **GitHub Pages**.

---

## 🌐 Sitio Web Publicado

Puedes acceder al portal de documentación en línea a través del siguiente enlace:
👉 **[Ver Portal de Documentación](https://lncproducciones.github.io/documentacion/)**

---

## 📂 Estructura del Repositorio

```text
documentacion/
├── .github/
│   └── workflows/
│       └── deploy.yml      # Workflow de GitHub Actions para el despliegue automático
├── docs/                   # Todo el contenido Markdown (.md) del portal
│   ├── img/                # Imágenes, logos y favicons
│   ├── {aplicacion}/       # Documentación de cada aplicación
│   ├── ayuda-soporte.md    # Información referente a la ayuda y soporte disponibles
│   └── index.md            # Portada principal del portal web
├── mkdocs.yml              # Configuración principal de MkDocs (menús, tema, plugins)
└── README.md               # Este archivo (guía del repositorio)
```
